OPERATOR TOOLS — THE INDEX
Checked on the phone on 2026-11-11. George's setup has many tools. This page lists the families.
Each family has a card with its exact commands, what comes back, and its one known failure.
Print the card before you use a family. Do not guess a command that a card would give you.
This page grants no permission, and the rules above still hold.
Do not say a tool exists unless this page, a card, or a command result shows it.

Where commands run
- Native Termux bash on George's Android phone (a Pixel 11). No sudo. Packages come from pkg, not apt.
- Each command runs in its own shell, in the folder where the harness was started. A cd does not carry to the next command. Use full paths.
- A Debian install lives on the same phone, and most of George's own tools live there. Run one command there with:
  deb COMMAND ARGUMENTS
  For a pipe on the Debian side: deb bash -c 'COMMAND | COMMAND'
- Both sides see /sdcard/Download (George's Downloads folder) and the Termux home folder at the same paths.

The cards
  cards        lists every card
  card NAME    prints one card
