Direct answers, bounded memory, optional confirmed Termux execution.

positional arguments:
  text                  Quoted input, or pipe text on stdin.

options:
  -h, --help            show this help message and exit
  --engine {openai,anthropic}
  --model MODEL
  --effort {low,medium,high,xhigh,max}
                        Reasoning effort on either engine (default: high).
  --chat, --interactive
                        Stay open for multiple turns; automatic on an
                        interactive terminal with no input.
  --timeout TIMEOUT
  --usage-log USAGE_LOG
  --new                 Fresh isolated turn (default); its ID becomes
                        available to --continue.
  -c, --continue
  --session NAME
  --turns TURNS         Exchanges kept in the session (1–1000000). The
                        character budget is the real limit.
  --history-chars HISTORY_CHARS
                        Maximum prior-history characters sent to the model
                        (0–4000000). Default: 2400000 on anthropic, 650000 on
                        openai, sized to each model window measured live on
                        2026-11-11.
  --no-normalize        Send exact typed input without phonetic substitutions.
  -x, --exec            Ask y/N before running the returned command in native
                        Termux.
  --exec-timeout EXEC_TIMEOUT
  --loop                Execute approved commands and feed results back until
                        completion or the turn ceiling; implies --exec.
  --max-turns MAX_TURNS
                        Maximum model turns per --loop task, including the
                        final answer (1–1000; default 200).
  -y, --yes             Explicitly approve every command for this invocation;
                        requires --exec or --loop.
  --recall QUERY        Search local history without an API call.
  -l, --listen          Use Android speech recognition through Termux:API.
  --listen-timeout LISTEN_TIMEOUT
  --no-web              Disable hosted web search and fetch.
  --web-max WEB_MAX     Total hosted lookup ceiling per model turn (2–50;
                        default 5).
  --image PATH          Attach PNG/JPEG/WebP/GIF bytes; repeatable.
  --file PATH           Attach PDF bytes; repeatable.
  --advisor [QUESTION]  Ask the other engine for a second opinion on a saved
                        session; needs -c or --session. In chat: /advisor
                        QUESTION.
  --advisor-turns ADVISOR_TURNS
                        Exchanges put in the advisor packet (1–50; default 3).
  --tools               List API tools, switches, lanes, and recorded
                        availability.
  --web-search          Search the web.
  --no-web-search       Disable web search.
  --web-fetch           Read a web page.
  --no-web-fetch        Disable web fetch.
  --history-cache       Cache the growing chat.
  --no-history-cache    Disable history cache.
  --memory              Read and write model notes on this phone.
  --no-memory           Disable memory.
  --code-execution      Run code in the provider sandbox.
  --no-code-execution   Disable code execution.
  --computer            See and act on a named screen.
  --no-computer         Disable computer.
  --browser             Drive the phone browser through its API toolset.
  --no-browser          Disable browser.
  --shell               Run local shell commands with approval.
  --no-shell            Disable shell.
  --hosted-shell        Run commands in an OpenAI container.
  --no-hosted-shell     Disable hosted shell.
  --text-editor         Read and edit local text files.
  --no-text-editor      Disable text editor.
  --apply-patch         Apply model-generated file patches.
  --no-apply-patch      Disable apply patch.
  --mcp-local           Use the phone MCP tools through agentbridge-call.
  --no-mcp-local        Disable mcp local.
  --mcp-remote          Let the provider call an authenticated MCP server.
  --no-mcp-remote       Disable mcp remote.
  --files               Upload attachments once and use provider file IDs.
  --no-files            Disable files.
  --file-search         Search an uploaded vector store.
  --no-file-search      Disable file search.
  --skills              Load versioned skills in a hosted runtime.
  --no-skills           Disable skills.
  --tool-search         Find and load deferred tool definitions.
  --no-tool-search      Disable tool search.
  --programmatic        Let sandbox code call other enabled tools.
  --no-programmatic     Disable programmatic.
  --context-editing     Clear old tool results in provider context.
  --no-context-editing  Disable context editing.
  --compaction          Replace older context with a provider summary.
  --no-compaction       Disable compaction.
  --background          Poll a long-running provider response.
  --no-background       Disable background.
  --image-generation    Generate an image and save its bytes.
  --no-image-generation
                        Disable image generation.
  --api-advisor         Ask a configured advisor model for help.
  --no-api-advisor      Disable advisor.
  --functions           Call the local command runner with JSON arguments.
  --no-functions        Disable functions.
  --custom-tools        Call the local runner with a free-form command.
  --no-custom-tools     Disable custom tools.
  --namespaces          Group the local function under a namespace.
  --no-namespaces       Disable namespaces.
  --computer-target COMPUTER_TARGET
                        phone, hidden:NAME, laptop, or yana for computer
                        tools.
  --no-recall           Skip the past-chat search for this run. In chat: /off
                        recall, /on recall.
  --fork SESSION [NEWNAME ...]
                        Start in a new session that is a full copy of SESSION.
                        The original is untouched. A question goes after --.
                        In chat: /fork [NEWNAME].
  --from NAME           A new session starts as a copy of NAME. `session
                        golden NAME` makes this the default for every new
                        chat; --new skips it.

Screen: in an approved --loop command, screen snap or look PATH attaches the
file to the next model turn. Run card screen for targets and commands. Past
chats: before each message the client searches the saved chats and sends the
best passages as a recall_notes data message. In chat: /off recall, /on
recall, /fork [NEWNAME], /rewind [N]. Session commands: sessions, session
show|export|fork|rewind|cut|splice|golden (card lanes). Notes: note
add|show|list (card memory).

Second gate, typed in the shell (a lane can type them too; see card lessons):
  rule add NAME --row N --action strip_sentence|reject --pattern 'REGEX' --bad 'SENTENCE'
                        Add a gate rule. Refused unless it matches its own bad
                        sentences and no known-good sentence.
  rule list             Every gate rule with its pattern, date and history row.
  rule drop NAME        Remove one gate rule.
  rule test [NAME] [--text 'WORDS']
                        Test the stored rules again; show what the gate does
                        to WORDS.

Always on, typed in the shell (README: Always on):
  job add [--lane L] [--session NAME] "TASK"
                        Queue a task on a lane; prints the job id at once. It
                        runs in the background with --loop -y.
  jobs [--all]          Every job with its state, one row each.
  job show ID [--full]  The full answer and every command the job ran.
  job stop ID | job wait ID
  agentd status|start|stop|restart|log [N]|url|password|install
  agentd tunnel [cloudflared|ngrok]
                        Put the jobs page on a public address.
  talk [--lane L] [--seconds N] [--clip FILE]
                        A spoken conversation with a lane. Say "stop" to end.

Mods, typed at the > prompt of a george or g1 chat (each ships on):
  /mods                 every mod, on or off, with one line on what it does
  /on NAME, /off NAME   switch one mod: length, plain-words, receipts, no-background,
                        undertaker, proof, narrator, tree, voice, voice-v,
                        memory-version, reindex, voiceline, autopilot
  /where                the open topics, top to current, and the whole topic tree
  /up                   close the current branch and go back to its parent
  /voice full|short|on|off   read each answer aloud: whole, first sentence, on, off
  /usage                tokens and calls today, this week, this month (also: usage)
  /autopilot GOAL       step after step until done, blocked, 150 steps or 10 hours;
                        /autopilot status, /autopilot go; Ctrl-C stops it
  v                     a line of just v: the phone listens, the words become the message
