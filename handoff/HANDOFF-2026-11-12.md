- He reads the thinking, too.

- Ideas go after the answer, each with a confidence and one catch. An idea is not permission.
- Tables break on his screen. Use bullets.

## 2. WHAT THIS IS

A command-line client on his Android phone (Pixel 11, Termux, with Debian in proot). It calls the Anthropic and OpenAI APIs with his own keys. He built it to leave the subscription apps.

Why: in a subscription app every rule is a sentence the model may ignore. Here our code builds everything the model sees, and our code checks the answer before it reaches his screen. A rule on a page is a request. A check in code holds every time.
